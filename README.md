# Google Demo（学習用UI模写）

Google検索トップページをHTML/CSS/JavaScriptで模写した、学習用のデモページです。
※実際のGoogleとは一切関係ありません。

## 概要

HTML・CSS・JavaScriptのみで実装した静的サイトです。フレームワークは使用せず、DOM操作やレスポンシブ対応の練習を目的としています。

## デモ

検索フォーム・ショートカット追加ポップアップなどを備えたGoogleトップページ風のUIです。

- 検索フォーム（検索アイコン／音声検索／画像検索／AIモード）
- ショートカット追加ポップアップ（モーダル）
- レスポンシブ対応（600px以下でレイアウト調整）
- 存在しないページ・未実装機能へのアクセス時に表示する404ページ

## 使用技術

- HTML5
- CSS3
- JavaScript（Vanilla JS）
- [Font Awesome](https://fontawesome.com/)（アイコン）
- [modern-css-reset](https://unpkg.com/modern-css-reset/)（CSSリセット）

## ディレクトリ構成

```
google-demo/
├── index.html      # メインページ
├── 404.html        # 未実装ページ用の404ページ
├── css/
│   └── style.css   # スタイル定義
└── js/
    └── main.js     # 検索フォーム・ショートカットポップアップの動作
```

## 主な機能

### 検索フォーム
入力欄・音声検索ボタン・画像検索ボタン・AIモードボタンを配置。実際の検索機能は未実装のため、送信や各ボタンのクリック時は404ページへ遷移します。

### ショートカット追加ポップアップ
「ショートカット...」ボタンからモーダルを開き、名前とURLを入力できます。両方の項目が入力されると「完了」ボタンが押せる仕組みにしています。

### レスポンシブ対応
600px以下の画面幅で、検索フォームやショートカットのレイアウト・フォントサイズを調整しています。

## ローカルでの確認方法
リポジトリをクローンし、`index.html`をブラウザで直接開くだけで動作します。

```bash
# リポジトリをダウンロード
git clone https://github.com/K-Tsubasa2026/google-demo.git

# フォルダに移動
cd google-demo

# ブラウザで開く
open index.html   # macOSの場合
start index.html  # Windowsの場合
```
